# GenericsJava 

Projeto desenvolvido para praticar conceitos fundamentais de **Java**, principalmente **Generics** e **Programação Orientada a Objetos (POO)**.

## Conceitos utilizados

* **Generics** — criação da classe `Cart<T>` para trabalhar com diferentes tipos de objetos.
* **Collections** — uso de `List` e `ArrayList`.
* **Herança** — classes `Maca` e `Banana` derivando de `Alimento`.
* **Classe abstrata** — criação da classe `Alimento`.
* **Interface** — implementação da interface `Comer`.
* **Polimorfismo** — utilização de `Cart<Alimento>` para armazenar diferentes tipos de alimentos.
* **Encapsulamento** — atributos privados com getters e setters.
* **Construtores e métodos** — organização e comportamento dos objetos.
* **Laço `for-each`** — percorrer e exibir os itens do carrinho.

##Objetivo

O objetivo foi **aprender e colocar em prática Generics junto com conceitos de POO**, criando um pequeno sistema de carrinho de alimentos.
